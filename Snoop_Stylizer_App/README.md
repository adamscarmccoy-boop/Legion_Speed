# 🎙️ Sovereign Audio Math: Medical Voice Stylizer (Mac Desktop)

This repository contains a full, standalone, mathematical DSP pipeline designed to intercept a live microphone stream and transform the acoustic signature into a target DNA footprint (e.g., Snoop Dogg's resonance).

Unlike typical AI wrappers that rely on Google Cloud TTS APIs (and suffer from 500ms+ network latency), this pipeline utilizes **Native PyTorch Autoencoders** and **Spotify's Pedalboard C++ Engine** to achieve < 2ms execution latency, making it perfect for real-time medical presentations in PowerPoint, Zoom, or Teams.

## 🏗️ Architecture overview

The pipeline operates in 3 distinct mathematical stages:

1.  **The Ingestion & Sovereign Truth Matrix (`snoop_voice_engine.ipynb`)**
    *   Uses robust `yt-dlp` (via `ytsearch1`) to rip 3 different target videos straight from YouTube (e.g. Snoop Dogg Howard Stern Interview).
    *   Uses `librosa` to extract the mean fundamental frequency (Pitch/f0) and the Timbral DNA (13 MFCC formants).
    *   Averages the footprints together to get an extremely stable target vector.
2.  **The PyTorch DSP Math (`snoop_voice_engine_run.py`)**
    *   Automatically calculates the mathematical Delta between the target's pitch/formants and the input source's pitch/formants.
    *   Saves the matrix weights as `snoop_dna.pt` and `snoop_pitch_delta.pt`.
3.  **The Mac Desktop Application (`snoop_voice_app.py`)**
    *   A local PyAudio / Tkinter application that loads the PyTorch weights into memory natively.
    *   Instead of making a network call, it constructs a real-time `pedalboard` DSP chain (Warm Compressors, Lowpass EQs, and Semantic Pitch Shifting) to instantly map the microphone input to the target DNA.
    *   Output is routed directly to the `BlackHole 2ch` virtual audio cable, enabling PowerPoint to pick up the manipulated voice in real-time.

## 🚀 Installation & Usage

**For Mac Users (The Presenter):**
1.  Double-click `install_mac.command`.
    *   *This will automatically install Homebrew, Python, BlackHole Virtual Audio Cable, PortAudio, and all pip dependencies.*
2.  The GUI will automatically launch.
3.  Set the **Input** to your physical microphone (e.g., `MacBook Pro Microphone`).
4.  Set the **Output** to `BlackHole 2ch`.
5.  In Microsoft PowerPoint (or Zoom), set your microphone source to `BlackHole 2ch`.
6.  Click **START STYLIZER**.
