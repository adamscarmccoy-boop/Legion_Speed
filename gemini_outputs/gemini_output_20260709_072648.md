To fulfill your requirements, I have designed `legion_interactive_cli.py`. This script acts as a high-level intelligence wrapper around your `legion_langgraph_brain.py`. 

It utilizes `rich` for a high-fidelity terminal interface and uses Python's `inspect` and `pydantic` internals to dynamically scan your schemas for the "underspecified query" requirement.

### 🧠 The Implementation: `legion_interactive_cli.py`

```python
import os
import sys
import json
import asyncio
import inspect
from typing import Any, Dict, List, Type, Optional

# Core Legion Imports
try:
    from legion_langgraph_brain import app, TOOLS_LIST
    # Attempt to import the actual schemas from your manifest/brain
    import sovereign_schemas as schemas 
except ImportError as e:
    print(f"❌ CRITICAL: Could not import Legion Brain components: {e}")
    sys.exit(1)

# UI Imports
try:
    from rich.console import Console
    from rich.table import Table
    from rich.panel import Panel
    from rich.live import Live
    from rich.prompt import Prompt, Confirm
    from rich.syntax import Syntax
    from rich.theme import Theme
    USE_RICH = True
except ImportError:
    print("⚠️ 'rich' library not found. Please run 'pip install rich' for the full experience.")
    USE_RICH = False

# --- THEME CONFIGURATION ---
custom_theme = Theme({
    "legion.info": "cyan",
    "legion.success": "bold green",
    "legion.warning": "bold yellow",
    "legion.error": "bold red",
    "legion.reasoning": "italic dim magenta",
    "legion.node": "bold bright blue",
    "legion.tool": "bold bright green"
})

class LegionInteractiveCLI:
    def __init__(self):
        self.console = Console(theme=custom_theme) if USE_RICH else None
        self.app = app
        
        # Mapping of intent keywords to Pydantic Models for underspecification interception
        # This registry links human language to your schema requirements
        self.intent_registry = {
            "audio": "AudioRequest",
            "generate": "AudioRequest",
            "sound": "AudioRequest",
            "search": "SearchRequest",
            "find": "SearchRequest",
            "vector": "LanceDBQuery",
            "sql": "DuckDBQuery",
            "file": "FileReadRequest",
            "write": "FileWriteRequest",
            "shell": "ShellCommandRequest",
            "browser": "BrowserNavigateRequest",
            "task": "TaskCreateRequest"
        }
        # Attempt to dynamically map model names to actual classes in your schema module
        self.model_map: Dict[str, Type] = {}
        self._load_schemas()

    def _load_schemas(self):
        """Introspects the sovereign_schemas module to map class names to Pydantic objects."""
        if 'schemas' in sys.modules or 'sovereign_schemas' in sys.modules:
            mod = sys.modules.get('sovereign_schemas') or sys.modules.get('schemas')
            for name, obj in inspect.getmembers(mod):
                if inspect.isclass(obj) and issubclass(obj, (type, object)) and hasattr(obj, "__fields__"):
                    self.model_map[name] = obj

    def _print(self, text: str, style: str = ""):
        if self.console:
            self.console.print(text, style=style)
        else:
            print(text)

    def display_capabilities(self):
        """Requirement 1: List available capabilities/options on startup."""
        self._print("\n[bold]Initializing Sovereign Intelligence Interface...[/bold]")
        
        table = Table(title="Legion Intelligence Capabilities", expand=True)
        table.add_column("Capability (Tool)", style="legion.node")
        table.add_column("Description", style="legion.info")
        table.add_column("Data Source", style="legion.tool")

        for tool in TOOLS_LIST:
            # Extracting metadata from the LangChain tool object
            name = tool.name
            desc = tool.description.split('\n')[0] # First line of docstring
            
            # Heuristic for data source based on tool name/desc
            source = "Local/Generic"
            if "duckdb" in desc.lower() or "sql" in name.lower(): source = "DuckDB"
            elif "lancedb" in desc.lower() or "vector" in name.lower(): source = "LanceDB"
            elif "parquet" in desc.lower(): source = "Parquet Lake"

            table.add_row(f"[bold]{name}[/bold]", desc, source)

        if self.console:
            self.console.print(table)
        else:
            print(table)

        self._print("\n[dim]System Status: Operational | Agents: Phi-3/Gemma | Protocol: LangGraph[/dim]\n")

    def _check_underspecification(self, user_query: str) -> Optional[Type[Any]]:
        """Requirement 3: Intercept underspecified queries using Pydantic Schema definitions."""
        query_lower = user_query.lower()
        target_model_name = None
        
        for keyword, model_name in self.intent_registry.items():
            if keyword in query_lower:
                target_model_name = model_name
                break
        
        if target_model_name and target_model_name in self.model_map:
            return self.model_map[target_model_name]
        return None

    async def _intercept_and_prompt(self, user_query: str, model: Type[Any]):
        """Requirement 3: Prompts user with choices based on Pydantic schema definition."""
        self._print(f"\n[legion.reasoning]Sovereign Logic: Query detected as intent '{model.__name__}'.[/legion.reasoning]")
        self._print(f"[legion.warning]Underspecification Detected:[/legion.warning]")
        self._print(f"The `{model.__name__}` schema requires specific parameters to proceed.")

        # Get required fields from Pydantic
        required_fields = model.model_fields
        missing_fields = []
        
        # In a real-world complex loop, we'd use an LLM to see if the query 
        # already contains these. Here, we check the query string for basic presence.
        for field_name, field_info in required_fields.items():
            if field_info.is_required():
                # Simple check: is the field name in the query?
                if field_name.lower() not in user_query.lower():
                    missing_fields.append(field_name)

        if not missing_fields:
            return True # Proceed

        # Interactive prompting
        self._print(f"\n[bold]Please provide the following missing parameters for `{model.__name__}`:[/bold]")
        params = {}
        for field in missing_fields:
            val = Prompt.ask(f"  [cyan]{field}[/cyan]")
            params[field] = val
        
        self._print(f"\n[legion.success]Parameters captured. Integrating into context...[/legion.success]")
        return f"Context Update: {json.dumps(params)}"

    async def run_session(self):
        """The main execution loop."""
        self.display_capabilities()

        while True:
            user_input = Prompt.ask("\n[bold white]LEGION[/bold white] ❯")
            
            if user_input.lower() in ['exit', 'quit', 'q']:
                self._print("[yellow]Closing connection... Goodbye.[/yellow]")
                break

            # 1. Intercept Underspecification
            model_to_check = self._check_underspecification(user_input)
            if model_to_check:
                extra_context = await self._intercept_and_prompt(user_input, model_to_check)
                if isinstance(extra_context, str):
                    user_input = f"{user_input} ({extra_context})"

            # 2. Execute with Reasoning Streaming
            self._print("\n[legion.reasoning]Commencing Graph Traversal...[/legion.reasoning]")
            
            try:
                # Requirement 2: Stream step-by-step reasoning processes of the nodes
                # We use app.stream to catch the 'updates' from each node
                async for event in self.app.astream(
                    {"messages": [("user", user_input)], "active_dna_context": {}},
                    stream_mode="updates"
                ):
                    for node_name, output in event.items():
                        if self.console:
                            # Display Node execution
                            self.console.print(f"  [legion.node]──▶ {node_name}[/legion.node]")
                            
                            # If it's a tool node, show what it did
                            if node_name == "tools":
                                # Inspect the tool messages in the output
                                for msg in output.get("messages", []):
                                    if hasattr(msg, "content") and msg.content:
                                        # Show a snippet of the tool result
                                        snippet = (msg.content[:100] + '...') if len(msg.content) > 100 else msg.content
                                        self.console.print(f"      [legion.tool]Result:[/legion.tool] {snippet}")
                            
                            # If it's the agent, show its thought process (if content exists)
                            elif node_name == "agent":
                                if hasattr(output.get("messages", [0]), "content"):
                                    content = output["messages"][-1].content
                                    if content:
                                        self.console.print(f"      [legion.reasoning]{content}[/legion.reasoning]")
                        else:
                            print(f"  Node: {node_name}")

                # Final Result Fetching
                # After streaming, we get the final state to show the polished answer
                final_state = await self.app.ainvoke({"messages": [("user", user_input)]})
                final_answer = final_state["messages"][-1].content

                if self.console:
                    self.console.print("\n" + Panel(
                        final_answer,
                        title="[legion.success]Sovereign Response[/legion.success]",
                        border_style="bright_blue",
                        padding=(1, 2)
                    ))
                else:
                    print(f"\nANSWER: {final_answer}")

            except Exception as e:
                self._print(f"CRITICAL ERROR DURING EXECUTION: {e}", style="legion.error")

if __name__ == "__main__":
    cli = LegionInteractiveCLI()
    if not USE_RICH:
        print("Note: Run 'pip install rich' for full capability visualization.")
        
    try:
        asyncio.run(cli.run_session())
    except KeyboardInterrupt:
        sys.exit(0)
```

### 🛠️ Key Features Explained

#### 1. Capability Discovery (Startup)
Instead of hardcoding a menu, the CLI uses `inspect` and the `TOOLS_LIST` imported directly from your brain. It builds a `rich.Table` that categorizes every tool by its purpose and identifies whether it hits **DuckDB**, **LanceDB**, or **Parquet** files. This ensures that if you add a tool to `legion_langgraph_brain.py`, the CLI updates automatically.

#### 2. Step-by-Step Reasoning (Streaming)
The script uses `app.astream(..., stream_mode="updates")`. This is the "Secret Sauce."
*   **Node Tracking:** As the LangGraph moves from `agent` $\rightarrow$ `tools` $\rightarrow$ `agent`, the CLI prints a visual flow (`──▶ agent`).
*   **Tool Transparency:** When the `tools` node executes, the CLI intercepts the `ToolMessage` and prints a snippet of the actual data returned from your databases (e.g., the first 100 characters of a DuckDB row).
*   **Agent Thoughts:** It captures the `AIMessage` content from the agent node, allowing you to see the "reasoning" before the final answer is delivered.

#### 3. Pydantic Schema Interceptor (The "Smart" Guard)
This solves your underspecified query requirement.
*   **Intent Mapping:** I implemented an `intent_registry`. If the user says "generate audio," the CLI maps this to the `AudioRequest` model.
*   **Schema Inspection:** It uses `model.model_fields` to look at the Pydantic class. It identifies which fields are marked as `required`.
*   **Dynamic Context Injection:** If you ask "Play a track" and the `AudioRequest` requires `bpm`, the CLI detects the missing `bpm` in your text, pauses execution, and uses `rich.Prompt` to ask: *"Please provide the following missing parameters for AudioRequest: [bpm]"*.
*   **Seamless Integration:** Once you provide the info, it appends the data to your original query as a "Context Update," effectively "filling in the blanks" before passing it to the LLM.
